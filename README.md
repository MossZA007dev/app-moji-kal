# 🍡 โมจิ · นับแคลและน้ำตาล (Mochi Cal & Sugar Tracker)
> แอปเว็บแอปพลิเคชัน (PWA) ติดตามแคลอรี น้ำตาล และความสม่ำเสมอในการดูแลสุขภาพ สำหรับใช้เองกับเพื่อนในกลุ่มอย่างมีความสุขและปลอดภัยต่อสุขภาพจิต

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **โภชนาการที่เน้นลดน้ำตาล (Sugar-Conscious Nutrition):**
   - คำนวณแคลอรีและน้ำตาล (g) เทียบกับเกณฑ์มาตรฐานองค์การอนามัยโลก (WHO: แนะนำไม่เกิน 24–25 กรัม/วัน)
   - ฐานข้อมูลอาหารและเครื่องดื่มไทยมาตรฐาน 30+ รายการ พร้อมระบบปรับระดับความหวาน (0%, 25%, 50%, 100%, 120%) และขนาดจาน/แก้ว
   - แจกแจงส่วนประกอบในจาน (Component Breakdown) เช่น ข้าวสวย, กับข้าว, ไข่ดาว

2. **ระบบกลุ่มเพื่อนและความปลอดภัยทางใจ (Psychological Safety & Privacy):**
   - **ฟีดกลุ่ม (Group Feed):** ดูกราฟความสม่ำเสมอและเป้าหมายของเพื่อนๆ ในกลุ่ม
   - **ความเป็นส่วนตัว 3 ระดับ:** 
     - *แชร์ครบถ้วน (Full):* เพื่อนเห็นทั้งตัวเลขและชื่อเมนู
     - *แชร์เฉพาะตัวเลขรวม (Summary Only):* เพื่อนเห็นเฉพาะแคลอรีและน้ำตาลรวม **ไม่เห็นชื่อเมนูหรือรูปภาพทั้งในหน้าจอและระดับ API**
     - *โหมดส่วนตัว (Private):* ซ่อนโปรไฟล์จากฟีดเพื่อนทั้งหมด
   - **มื้อส่วนตัว (Private Meal Toggle):** แม้ตั้งแชร์ครบถ้วน ก็ยังสามารถเลือกซ่อนเฉพาะบางมื้อที่ไม่อยากให้เพื่อนเห็นได้ (แสดงเป็น "🔒 เมนูส่วนตัว")
   - **ชาเลนจ์สร้างนิสัย:** วัดที่ความสม่ำเสมอ (Streak) ไม่แข่งขันว่าใครกินน้อยที่สุด และสามารถกด **"ออกจากชาเลนจ์"** ได้ทันทีโดยไม่มีการแจ้งเตือนให้อับอาย
   - **คุมแคลอรีขั้นต่ำ (≥1,200 kcal):** ระบบไม่มีการชมเชยการอดอาหารหรือจำกัดอาหารรุนแรง หากทานน้อยเกินไปจะมีข้อความเตือนด้วยความห่วงใย
   - **แดชบอร์ดกิจกรรม & อันดับเหรียญคอยน์ (Social Dashboard & Leaderboard):**
     - **Live Activity Stream:** ติดตามความเคลื่อนไหวล่าสุดของเพื่อนในแก๊งแบบเรียลไทม์
     - **แท่นรับรางวัลโพเดียม (Top 3 Podium):** จัดอันดับผู้สะสมเหรียญโมจิคอยน์ (🪙) สูงสุด
     - **รายชื่อสมาชิกและการกดดูโปรไฟล์เพื่อน (Member Profiles):** กดดูตัวละครโมจิ, หมวก, สถิติ Streak, เหรียญคอยน์, ตราสัญลักษณ์สุขภาพ (Badges) และมื้ออาหารที่เคารพความเป็นส่วนตัว
     - **ระบบส่งกำลังใจ (Interactive Cheers):** ส่งหัวใจ (💖), ไฮไฟฟ์ (✋), โมจิ (🍡), สู้ๆ (🔥), ปรบมือ (👏) พร้อมมอบเหรียญคอยน์ให้เพื่อนทันที!

3. **ระบบอัจฉริยะประหยัดโควตา (AI & Group Verified Cache):**
   - **Group Verified Knowledge Cache:** เมนูที่เพื่อนในกลุ่มเคยยืนยันแล้ว ระบบจะบันทึกลงแคชความรู้ของกลุ่ม เมื่อมีคนสั่งซ้ำ ระบบจะดึงค่าจากแคชทันทีโดย **ไม่เสียโควตา AI**
   - **AI Rate Limiting:** จำกัดการเรียก AI สูงสุด 15 ครั้ง/คน/วัน เพื่อคุมต้นทุนและป้องกันฟรีเทียร์ล่ม
   - **Graceful Fallback:** หาก AI โควตาเต็มหรือต่อไม่ติด ระบบจะสลับไปใช้ฐานข้อมูลอาหารไทยมาตรฐานทันที พร้อมเปิดให้ผู้ใช้ปรับแก้ตัวเลขได้ก่อนบันทึกเสมอ

4. **ประสบการณ์การใช้งานจริง (Real-World UX):**
   - **บันทึกย้อนหลัง & มื้อดึก (Late-Night Handling):** บันทึกมื้อของเมื่อวานได้ตลอดเวลา และเมื่อบันทึกช่วง 00:00 - 04:00 จะมีปุ่มถามทันทีว่านับเป็นมื้อของเมื่อวานหรือวันนี้
   - **ปุ่มเลิกทำ (Undo Delete):** เมื่อลบมื้ออาหารโดยไม่ตั้งใจ จะมีปุ่มแจ้งเตือนให้กดเลิกทำ (Undo) คืนค่าได้ทันที
   - **พิมพ์ / พูดเล่า (Voice Input):** รองรับ Web Speech Recognition ภาษาไทย
   - **แชร์การ์ดรูปภาพ (Canvas Card):** ส่งสรุปรายวันพร้อมมาสคอตโมจิลง LINE กลุ่มได้ง่ายๆ

## ⚙️ การตั้งค่าและการจัดการโมเดล AI (Maintenance & API Keys)

### 1. จุดแก้ไขโมเดล AI (Centralized Model Configuration)
ชื่อโมเดล AI รวมอยู่ที่จุดเดียวในไฟล์ `gemini.mjs`:
```javascript
export const GEMINI_MODEL = process.env.GEMINI_MODEL || 'gemini-2.0-flash';
```
หากต้องการเปลี่ยนเวอร์ชันโมเดลในอนาคต (เช่น เมื่อ Google อัปเดตโมเดลเป็นรุ่นใหม่) สามารถ:
- แก้ไขค่าเริ่มต้นใน `gemini.mjs` บรรทัดที่ 9
- หรือตั้งค่า Environment Variable: `GEMINI_MODEL="gemini-2.5-flash"`

### 2. การจัดการ API Keys & Secrets
- **Gemini API Key:** สามารถใส่ผ่านหน้าเว็บที่เมนู `ตั้งค่า ⚙️ -> คีย์เชื่อมต่อระบบ (API Keys)` (บันทึกใน `data/settings.json` แบบปลอดภัย ไม่ส่งกลับไปฝั่ง Client) หรือผ่าน Environment Variable `GEMINI_API_KEY`
- **Google Client ID:** ตั้งค่าผ่านหน้าต่างเดียวกันเพื่อเปิดใช้งาน Google Sign-In
- **ความปลอดภัยของ Git:** ไฟล์ `data/settings.json`, `data/*.db`, `data/backups/`, `.env` ถูกระบุไว้ใน `.gitignore` เรียบร้อยแล้ว **จะไม่ถูก commit ขึ้น GitHub**

## 🛡️ การป้องกันระบบฟรีล่ม & แผนสำรองข้อมูล (Free-Tier Protection)

1. **การสำรองข้อมูลอัตโนมัติ (Automated Weekly Backup):**
   - ระบบจะตรวจเช็กและสำรองฐานข้อมูลเป็นไฟล์ JSON ทุก 7 วันอัตโนมัติ เก็บไว้ที่โฟลเดอร์ `data/backups/backup_YYYY-MM-DD.json`
   - สามารถกดสำรองข้อมูลทันทีได้ที่หน้า `ตั้งค่า ⚙️ -> สำรองข้อมูลอัตโนมัติ`
2. **การคืนค่าข้อมูลจากไฟล์สำรอง (Recovery):**
   - ไฟล์สำรองเก็บโครงสร้างผู้ใช้ มื้ออาหาร เมนูประจำ และฐานความรู้กลุ่ม สามารถนำกลับมา import เข้า SQLite ได้ตลอดเวลา
3. **กรณี Deploy บนบริการ Cloud ฟรี:**
   - **Supabase:** โครงการฟรีจะถูก Pause หากไม่มีการใช้งานติดต่อกัน 7 วัน สามารถปลุกกลับมาได้โดยการกด Resume ใน Supabase Dashboard
   - **Cloudflare Workers:** โควตาฟรี 100,000 requests/วัน เพียงพอสำหรับการใช้งานในกลุ่มเพื่อนอย่างสบายใจ

## 🤝 ข้อตกลงร่วมกันของกลุ่ม (Group Agreement & Culture)

เพื่อให้แอปนี้เป็นพื้นที่ปลอดภัยและช่วยให้ทุกคนมีสุขภาพที่ดีอย่างยั่งยืน สมาชิกทุกคนในกลุ่มตกลงร่วมกันดังนี้:

1. **ไม่ตัดสิน ไม่ล้อเลียน (No Food Shaming):**
   - เรื่องการกินเป็นเรื่องส่วนบุคคล ทุกคนมีวันที่อยากกินของหวานหรือวันที่คุมอาหารได้ดี
   - เราไม่ใช้ตัวเลขแคลอรีหรือน้ำตาลของเพื่อนมาเป็นประเด็นล้อเลียนหรือกดดันกัน
2. **เคารพความเป็นส่วนตัว (Respect Privacy Choices):**
   - หากเพื่อนคนใดเลือกตั้งค่า "แชร์เฉพาะตัวเลขรวม" หรือทำเครื่องหมาย "เมนูส่วนตัว" เราจะเคารพพื้นที่ส่วนตัวนั้นโดยไม่ซักไซ้
3. **โฟกัสที่ความสม่ำเสมอ ไม่ใช่การกินน้อยที่สุด (Consistency over Restriction):**
   - สุขภาพที่ดีเกิดจากความสม่ำเสมอในระยะยาว ไม่ใช่การอดอาหาร
   - ร่างกายต้องการพลังงานขั้นต่ำอย่างน้อย 1,200 kcal/วัน เพื่อระบบเผาผลาญที่สมบูรณ์
4. **ความสมัครใจในชาเลนจ์ (Voluntary Participation):**
   - การเข้าร่วมหรือออกจากชาเลนจ์เป็นไปตามความสมัครใจ ทุกคนสามารถกดออกจากชาเลนจ์ได้ตลอดเวลาเมื่อรู้สึกเหนื่อยล้า โดยไม่มีใครมองว่ายอมแพ้
